# dc34-badge-cam

Photos captured on a DEF CON 34 Baosec-lite badge's onboard camera, browsable at:

https://kimbermuffin.github.io/dc34-badge-cam/

Built as part of a project turning the badge's camera into a general-purpose photo booth —
custom firmware adds live-preview capture, color image support, and a ring-buffer photo store
to the badge itself, plus a fast USB pull tool and this viewer.
